# Lista de Tarefas

Este projeto é uma simples aplicação web de lista de tarefas desenvolvida com HTML, CSS e JavaScript.

## O que a aplicação faz
- Permite adicionar tarefas por meio do campo de texto
- Armazena as tarefas no navegador usando localStorage
- Permite remover tarefas com o botão "Apagar"
- Mantém as tarefas salvas mesmo após atualizar a página

## Estrutura do projeto
- `CriandoUmaListaDeTarefas.html` — página principal da aplicação
- `assets/css/Aula67-CriandoUmaListaDeTarefas.css` — estilos da interface
- `assets/js/Aula67-CriandoUmaListaDeTarefas.js` — lógica da lista de tarefas

## Como executar
1. Abra o arquivo `CriandoUmaListaDeTarefas.html` no navegador, ou
2. Inicie um servidor local na pasta do projeto, por exemplo:
   ```bash
   python3 -m http.server 8000
   ```
3. Acesse no navegador:
   ```text
   http://127.0.0.1:8000/CriandoUmaListaDeTarefas.html
   ```
